# MONOPILE X enquiries and meeting booking

## Published experience

The **Overview** tab introduces the research, preliminary results, validation
pathway and industry applications. The **Discuss your project** button opens
a focused enquiry dialog.

The current enquiry route opens an email draft addressed to
`amin.ghotbi@rmit.edu.au`, with `aminghotbi@gmail.com` copied. The visitor must
send that draft. The topic selector offers technical discussion, validation
data, collaboration and meeting requests.

The **Request a meeting** buttons open the same enquiry form, with a prompt for
discussion topics, suggested times and a time zone. They do not claim to reserve
a time or read Amin's calendar.

## Connect direct enquiries

In an owner-managed Microsoft Forms account, create **MONOPILE X industry
enquiry** with these fields:

| Field | Type | Required |
| --- | --- | --- |
| Name | Short text | Yes |
| Organisation | Short text | No |
| Email | Short text | Yes |
| Topic | Choice: Technical discussion; Validation data; Collaboration; Meeting request | Yes |
| Message | Long text | Yes |

Choose **Anyone can respond** if available in the RMIT account, so external
industry contacts can submit. Enable response notifications if desired. Copy
the public **Collect responses** link into `enquiryFormUrl` in
`assets/industry-config.js`, then publish the change. Use the response link,
not an editing or collaboration link.

When configured, the website replaces the email-draft form with a Microsoft
Forms embed, loaded only when the enquiry panel opens. An external form link
is also available in case the embedded form cannot load. Responses are stored
in the owner's Microsoft Forms account; this website does not claim successful
submission merely because the form has opened.

The current configuration accepts HTTPS response URLs on `forms.office.com`,
`forms.cloud.microsoft` and `forms.microsoft.com`. A real owner-provided link is
required; no third-party destination has been invented or activated.

## Connect live meeting availability

Create a **MONOPILE X research discussion** meeting type in Microsoft Bookings
or an existing Calendly/Cal.com account. Set a duration of 20 or 30 minutes,
choose the actual calendar and available times, and configure the meeting
location or video link. Copy that meeting type's public booking URL into
`bookingUrl` in `assets/industry-config.js`, then publish the change.

The meeting buttons will then say **Choose a meeting time** and open the real
booking page. No available slots, calendar reservations or confirmations are
generated by the static GitHub website.

## Verify after connecting

1. Open the public website and check that the enquiry form is available to an
   external visitor without access to the owner's account.
2. Submit one clearly labelled test enquiry and check that the owner receives
   it in Microsoft Forms. Only then treat direct submission as verified.
3. Open the booking page and check the correct meeting type, duration, time
   zone and availability. Avoid making a real reservation during a read-only
   check.
4. Confirm that the public links never expose the owner's editing interface.

The Google Analytics events do not include enquiry fields, messages or
suggested meeting times. An enquiry opening or email draft is not a confirmed
submission or booking.
